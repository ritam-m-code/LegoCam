# Recorded experiment snapshot

`current_rig` contains numerical results, setup settings, candidate-model comparisons and the reference reuse audit from the 2026-11-15 experiment. The optical dimensions were calculated from real captures. The first LEGO brick's corrected caliper readings are 31.80 × 15.79 mm; the earlier entry is retained locally in the comparison history.

Run `python run.py example` to show these recorded values without opening a camera. This is not a live session and does not include raw frames. New camera measurements require a transferred local session or a new setup/calibration. The local full backup command is `python run.py package --include-images`.
